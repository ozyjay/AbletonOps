# A two-bar groovy-house audition pattern

Original musical suggestion; not an Ableton factory pattern or a tested kit review.

Use 4/4 at 124 BPM. Count each bar as 16 sixteenth-note steps. Repeat this core in both bars:

| Sound | Steps | Suggested velocity (1–127) |
| --- | --- | --- |
| Kick | 1, 5, 9, 13 | 100 |
| Clap/snare | 5, 13 | 90 |
| Open hat | 3, 7, 11, 15 | 60–75 |
| Closed hat | 2, 4, 6, 8, 10, 12, 14, 16 | Alternate 35 / 55 |
| Short percussion | 4, 10, 15 | 40–65 |

In bar two, try one quiet snare ghost at step 12 and move percussion step 10 to 11. Reduce hat density if the kit becomes busy. Use these values as relative targets if editing directly on Move.

Begin with Groove at 0%, then try roughly 15–30% and listen for the bass/drum relationship. This is a suggested range, not a universal setting. Move's 100% Groove is triplet sixteenth swing, so a displayed value should not be equated to another sequencer's swing percentage. See the [Move manual, Groove](https://www.ableton.com/en/move/manual/).

Keep the kick and backbeat clear; let quieter accents provide movement. Check pad assignments before comparing presets. Record favorites in [the kit guide](drum-kits.md).
