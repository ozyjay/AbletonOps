## What makes a bass line groove?

For house, disco-house and funk-influenced electronic music, **rhythmic placement and note length** can matter as much as pitch selection. Aim for a repeated hook that interacts with the kick instead of filling every gap.

1. **Start sparse.** Use root notes and a single rhythmic idea. Listen with the drums before adding notes.
2. **Use syncopation.** Try occasional bass attacks on the offbeat or a sixteenth before a beat, not just on quarter-note pulses.
3. **Control note length.** Mix short, clipped notes with an occasional held note. Silence can make the next attack feel stronger.
4. **Use octaves and fifths sparingly.** These create movement without changing the basic harmony; passing notes can lead into the next root.
5. **Shape dynamics.** Make structural notes stronger, connecting notes softer; avoid random velocities.
6. **Lock with the kick deliberately.** Sometimes double a kick for impact; at other times place bass between kicks for a call-and-response feel.
7. **Use small variations.** Keep the main motif recognisable, with a fill or anticipation at the end of every second or fourth bar.
8. **Evaluate the low end in context.** A busy kick and a sustained sub-bass can mask each other; adjust arrangement, envelopes and, in Live, processing where needed.

These are musical suggestions, not rules for all genres.

## On Ableton Move (four-track limit)

A practical sketch allocation is **Track 1 drums, Track 2 bass, Track 3 chords/stabs, Track 4 hook or texture**. The bass must earn its track: try composing the full drum-and-bass relationship with only Tracks 1 and 2 before adding harmonic material.

Select a bass-capable preset, enter a two-bar melodic pattern, and adjust note lengths and velocities where supported by the current device/firmware. Start with minimal groove processing, then audition more swing while listening to the kick, hi-hats and bass together. Avoid assuming a swing percentage is equivalent across devices.

## In Ableton Live 12

Program the same pattern in a MIDI clip with a monophonic bass instrument. Compare an unquantised or lightly adjusted line against strict grid timing. Test clip groove, velocity and articulation separately so you can hear each effect. If kick and bass mask each other, first modify note lengths or pitch register before reaching automatically for sidechain compression.
