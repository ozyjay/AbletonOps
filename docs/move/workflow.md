# Move workflow notes

Checked 1 November 2026.

## Audition a kit

Save a starting Set. Select the drum track, enter Device View and focus the whole track preset. Click the wheel to browse, then scroll while the clip loops. Highlighted presets load immediately. Distinguish the whole rack from a pad's sample when browsing. See [Ableton's preset instructions](https://help.ableton.com/hc/en-us/articles/15616909965596-Presets-on-Move-and-Note).

After changing kits, verify pad roles and save promising versions separately. Log the exact preset name and firmware in [drum-kits.md](drum-kits.md).

## Continue in Live

Use the documented Move Manager or Ableton Cloud workflow to transfer Sets. Check version compatibility before opening them in Live: Ableton specifies Live 12.4 for Sets from Move 2.0.0. See [Move release notes](https://www.ableton.com/en/release-notes/move-1/) and the [Move manual](https://www.ableton.com/en/move/manual/).

Keep Set backups and audio assets outside this documentation repository until a deliberate storage policy is chosen.
