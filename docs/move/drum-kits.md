## Groovy-house audition shortlist

These are suggested experiments, not ratings from listening tests. A kit's name alone does not establish its samples or sound.

| Candidate | What to test |
| --- | --- |
| 909 | First reference for a steady house pulse: does the kick leave room for your bassline? |
| 707 / 606 | Compare clap attack and hat articulation against the 909 at matched loudness |
| Golden / Oracle Dirty | Compare character and useful percussion against the same reference pattern |
| DECAP DTK 1–3 | Check punch, decay and whether the percussion fits your bass rhythm |
| LDre Cafe / Cozy / Mellow | Test at quiet velocities for a relaxed groove; names do not prove warmth |
| Perc Kitchen / Perc Spirit / Tamuz kits | Search for short organic accents that complement the core beat |
| KUCKA / BADSISTA kits | Explore alternate textures; keep only sounds that serve the groove |

Start with 909, Golden, Oracle Dirty, LDre Cozy and Perc Kitchen. Prefer a controlled kick tail, a clear backbeat and hats that respond musically to accents. Try the existing library before deciding whether additional packs are useful.

## Compare fairly

1. Build the [two-bar audition pattern](groove-programming.md) at 124 BPM.
2. Save the starting Set, then keep the pattern constant while browsing whole-track presets.
3. Confirm which pads contain kick, clap and hats after each swap; different mappings can invalidate the comparison.
4. Compare at similar perceived volume. Listen first with bass, then drums alone.
5. Save favorites as separate Sets and record exact display names, firmware, pad map and observations.

Ableton documents immediate preset replacement while scrolling, including auditioning against a playing clip. See [Presets on Move and Note](https://help.ableton.com/hc/en-us/articles/15616909965596-Presets-on-Move-and-Note).

## Limits and custom kits

The [Move manual](https://www.ableton.com/en/move/manual/) describes four tracks and Drum Racks with 16 drum pads. One rack can hold the core beat and percussion on one track; this does not imply 16 independent tracks or unrestricted Live devices. Its Groove control reaches triplet sixteenth swing at 100%; begin subtly and adjust by ear.

Ableton's [preset export guide](https://help.ableton.com/hc/en-us/articles/15616909965596-Presets-on-Move-and-Note) describes an experimental Live 12.1+ export route using `-_Feature.ExportPresetsToAbl` in Options.txt. The drum structure is an outer Instrument Rack containing a Drum Rack with Drum Sampler pads, with supported effects in the documented slots. Export the outer rack as `.ablpresetbundle`. Arbitrary Live racks, plugins and Simpler-based kits are not automatically compatible; follow the supplied templates and supported-device list. Live-mapped rack macros are not displayed on Move.
