## Layout

```text
docs/
  move/             Drum kits, groove recipes and hardware workflows
  live/             Live knowledge and workflows
  integrations/     Connections to other tools and projects
  development/      Roadmap and version requirements
sdk/
  control-surface/   Future controller integrations
  max-for-live/      Future Max for Live devices
  experiments/       Future Extensions SDK and other prototypes
examples/            Small reproducible patterns and examples
tools/               Future utilities and scripts
```

Reserved folders contain `.gitkeep` files. No SDKs, dependencies or executable experiments are installed yet.

## Knowledge conventions

Date source checks; link primary documentation for product facts. Label community inventories, uncertain transcriptions, subjective audition ideas and on-device observations separately. Record firmware, Live version and kit pad mappings with listening notes. Do not treat a historical catalogue as the inventory installed on a particular Move.

Keep proprietary factory samples, downloaded SDK packages, credentials and large Live Sets outside Git unless their licensing and storage are explicitly addressed. No repository license is assumed.
